## 🚀 Featured project: [MrHope_BankingApp](https://github.com/MrHope123/MrHope_BankingApp)

A secured banking REST API built with Spring Boot.

- **Authentication:** sign-up and login with JWT, passwords hashed with BCrypt
- **Account ownership:** every customer can only access their own account, and the rule is enforced in the service layer, not just at the edge
- **Money operations:** credit, debit and transfer run in transactions with row locking, so simultaneous requests cannot lose an update
- **Clean API:** request validation, consistent JSON errors with correct HTTP statuses, Swagger UI
- **Tested and automated:** 80+ unit, controller and integration tests (including forged and expired tokens and cross-account access attempts), a Dockerfile, and GitHub Actions CI on every pull request
